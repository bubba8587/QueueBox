## Decision

QueueBox exists so one person can run several coding agents in a repository and always know where each is working and what waits on them.

## Why

Several agents in one codebase are only manageable if the person can see them. Goal drafted by an agent on the author's instruction (2026-11-22: 'you can generate them all'); unratified until the author ratifies it.
