## Decision

QueueBox installs into any repository without pulling packages and without importing the host's code; the host carries only its board file.

## Why

It has to work beside any project and any agent, so it can't lean on either. Author, 2026-11-22: 'you're authorized to add whatever leaves'; unratified.
